# Payment Provider: Tilopay

Odoo 18 payment provider integration for [Tilopay](https://tilopay.com).

## Features

- Portal payments on sale orders (`/my/orders/...`)
- Payment links generated from the backend

## Configuration

1. Install the module.
2. Open **Accounting → Configuration → Payment Providers**.
3. Enable **Tilopay** and enter the API credentials.
4. Publish the provider and assign it to the desired payment method.
